# T-IAM-004: Изоляция чтения между проектами

## Требование
`req~T-IAM-004~1`

Система должна показывать пользователю данные проекта только при наличии у него роли в этом проекте.

Needs: impl, itest
Tags: sso

## Обоснование
Модель «все вошедшие видят всё» не подходит компании, где в одной установке работают команды с разными данными и клиентами.

## Критерии приёмки
- Пользователь без роли в проекте получает отказ при чтении его объектов через интерфейс и API
- Поиск, списки и отчёты не показывают объекты проектов, в которых у пользователя нет роли
- Проверка выполняется на сервере, а не только скрытием элементов интерфейса
