# T-IAM-008: Секреты из внешнего хранилища секретов

## Требование
`req~T-IAM-008~1`

Система должна получать свои секреты из внешнего хранилища секретов при запуске или по запросу, без хранения их в собственной базе данных и файлах конфигурации.

Needs: req
Tags: secrets

## Обоснование
Секреты в базе данных приложения, зашифрованные ключом из файла окружения, не ротируются и копируются вместе с резервными копиями.

## Критерии приёмки
- В базе данных и в репозитории конфигурации нет значений секретов, только ссылки на них
- Ротация секрета в хранилище применяется без пересборки и без ручного редактирования файлов
- Учётные данные для доступа к внешним системам выдаются с ограниченным сроком жизни там, где внешняя система это поддерживает
