# X-NFR-001: Доступность публичного API не ниже 99,9 % в месяц

## Требование
`req~X-NFR-001~1`

Публичный API доступен не менее 99,9 % времени за календарный месяц, исключая согласованные окна обслуживания.

Needs: impl, itest

## Обоснование
Типовое требование для старта; адаптируйте пороги под свой проект.

## Критерии приёмки
- Синтетическая проверка `/healthz` каждые 60 с из двух внешних точек
- Дашборд SLO с бюджетом ошибок за 30 дней
- Алерт при сгорании бюджета быстрее 2 % в час
