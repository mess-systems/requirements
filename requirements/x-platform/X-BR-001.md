# X-BR-001: Мультиарендность с изоляцией данных клиентов

## Требование
`req~X-BR-001~1`

Данные каждого клиента изолированы: пользователь одного клиента не может прочитать или изменить данные другого.

Needs: impl, itest

## Обоснование
Типовое требование для старта; адаптируйте пороги под свой проект.

## Критерии приёмки
- Идентификатор клиента обязателен во всех запросах к данным
- Автотест на межклиентский доступ
- Аудит запросов с идентификатором клиента
