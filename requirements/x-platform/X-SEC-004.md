# X-SEC-004: Сканирование образов и блокировка критических уязвимостей

## Требование
`req~X-SEC-004~1`

Каждый собранный образ сканируется; образы с критическими уязвимостями без исключения не попадают в окружение `prd`.

Needs: impl

## Обоснование
Типовое требование для старта; адаптируйте пороги под свой проект.

## Критерии приёмки
- Сканер в CI, отчёт прикладывается к PR
- SBOM публикуется вместе с образом
- Исключения оформляются с владельцем и сроком
