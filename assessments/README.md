# Оценки продуктов

Справочные документы: какие типовые требования набора или профиля закрывает конкретная версия продукта (есть, частично, нет, не найдено) со ссылками на документацию и код по тегу релиза. Оценка не является требованием. Её выводы используются в карточках tech-radar (кольцо и раздел «Alternatives considered») и в blueprints.

Имя файла: `<product>-<version>.md`.
