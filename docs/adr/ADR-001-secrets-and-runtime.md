# ADR-001: Секреты в менеджере секретов, доставка в рантайм через CSI

- Статус: accepted
- Дата: 2026-01-15
- Связанные требования: X-SEC-002, X-NFR-001

## Контекст
Сервисы x работают в Kubernetes. Нужно убрать секреты из git и переменных CI (X-SEC-002), не ухудшив доступность (X-NFR-001).

## Варианты
| | Менеджер секретов + CSI | Sealed Secrets в git | Переменные CI |
|---|---|---|---|
| Ротация | централизованная | перешифровка в git | вручную |
| Аудит доступа | есть | нет | частичный |
| Отказ менеджера | под не стартует (кэш CSI смягчает) | не влияет | не влияет |

## Решение
Менеджер секретов (HA, 3 узла) + Secrets Store CSI. Sealed Secrets только для bootstrap менеджера.

## Последствия
Менеджер секретов становится зависимостью старта подов и поэтому входит в SLO (X-NFR-001). Сканер секретов в CI обязателен.
