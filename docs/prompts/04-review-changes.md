# Промпт: разобрать изменения продукта
```
Разбери коммиты <from>..<to> в <репо продукта> относительно реестра требований.
Ищи: новые поля с ПДн без класса/срока, захардкоженные значения (ID клиентов, площадок), опасные миграции (блокировки, переписывание таблиц), отступления от ADR, тип времени без зоны.
Выход:
1. Заметка docs/changes/<дата>.md: что изменилось, риски, вопросы владельцу.
2. Для каждого существенного риска подготовь черновик требования (status: draft, hypothesis: true, source: хэши) или доказательство к существующему.
3. Один PR, мерж только человеком. Ничего не публикуй вне репо.
```
