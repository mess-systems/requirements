# Промпт: создать требование
```
Создай новое требование в репо требований.
Суть: <что должно быть верно, для кого, с какими порогами>.
Правила: .cursor/rules/requirements.mdc, reqs.config.yaml.
1. Выбери type и scope из конфига, найди следующий свободный номер для <PREFIX>-<TYPE>.
2. Скопируй templates/requirement.md, заполни front matter (status: draft, owner указывает роль).
3. В разделе «Требование» одна-две проверяемые фразы, маркер req~ID~1, строка Needs.
4. В «Критериях приёмки» 3–5 измеримых пунктов.
5. Запусти make check, исправь ошибки, сгенерируй реестр. Открой PR, статус не повышай.
```
