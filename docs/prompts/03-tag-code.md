# Промпт: разметить код тегами OFT
```
В этом репо реализации расставь теги OpenFastTrace.
Список требований: <путь к REGISTER.md или register.json репо требований>.
1. Для каждого требования со статусом approved/implemented найди место, которое его реализует.
2. Добавь комментарий [impl->req~ID~1] рядом (код, YAML, Terraform), для тестов ставь [utest->req~ID~1] / [itest->req~ID~1].
3. Не ставь тег, если реализация частичная; перечисли такие места в описании PR.
4. Прогони oft trace <repo-требований> . и приложи сводку покрытия к PR.
```
