# Промпт: связать требование с ADR
```
Есть решение: <описание>. Затрагивает требования: <ID...> (или найди их по REGISTER.md).
1. Создай docs/adr/ADR-NNN-<slug>.md по templates/adr.md (следующий номер), заполни Варианты таблицей и Последствия.
2. В строке «Связанные требования» перечисли ID; в каждом из них добавь ADR в links.adr.
3. make check, один PR на ADR и связи.
```
