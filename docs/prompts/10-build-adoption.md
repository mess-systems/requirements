# Промпт: собрать adoption.yaml для проекта

```
Собери adoption.yaml для проекта <проект> по профилям <профили>. Читай docs/adoption.md.

1. Разверни профили с учётом includes и перечисли все требования уровня MUST.
2. Для каждого найди требование проекта, которое его покрывает. Если покрывает почти дословно, режим inherit с параметрами проекта. Если требование проекта строже или конкретнее, режим refine: добавь в него refines и строку Covers.
3. Если требование не относится к проекту, режим waive с reason, owner (role-…) и review не дальше чем через 12 месяцев. Не исключай требование только потому, что его трудно выполнить: в этом случае предложи priority S или C и вопрос владельцу.
4. SHOULD и MAY предложи списком, решение за владельцем.
5. make register && make check. Покажи таблицу «требование — режим — чем покрыто — вопрос».
```
