# Политика статусов

| Статус | Кто ставит | Условие |
|---|---|---|
| draft | любой, агент | черновик, может быть неполным |
| proposed | автор | все разделы заполнены, критерии проверяемые |
| approved | владелец (человек) в PR | согласовано, можно реализовывать |
| implemented | автор реализации | есть `[impl->req~ID~1]` в репо реализации |
| verified | владелец | есть `links.verified_by` (тест/протокол), покрытие OFT зелёное |
| deprecated | владелец | не удаляем файл, указываем замену в теле |

- Статус покрытия OFT в CI **рекомендательный** (advisory): теги живут в других репо, их PR не должны ломать репо требований.
- Версию требования (`req~ID~2`, `version: 2`) меняют, когда меняется смысл; старые теги `~1` в коде OFT покажет как устаревшие.
- Агент никогда не повышает статус выше `proposed`.
