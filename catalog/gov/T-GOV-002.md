# T-GOV-002: Сроки хранения всех видов данных

## Требование
`req~T-GOV-002~1`

Система должна удалять или обезличивать данные каждого вида по истечении срока хранения, заданного политикой.

Needs: impl, itest
Tags: policy

## Обоснование
Беседы с агентами, артефакты прогонов и журналы содержат код, секреты по ошибке и персональные данные. Бессрочное хранение увеличивает ущерб от утечки.

## Критерии приёмки
- Срок хранения задаётся отдельно для бесед, артефактов, журналов работы и вложений, по умолчанию `{default_retention_days}` дней
- Удаление по сроку попадает в журнал аудита без содержимого удалённых данных
- Срок хранения журнала аудита задаётся отдельно и не сокращается этой политикой

## Параметры

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `default_retention_days` | 180 дней | срок хранения по умолчанию |
