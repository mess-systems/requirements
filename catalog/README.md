# Каталог типовых требований

Один файл на требование: `catalog/<domain>/T-<DOM>-NNN.md`, домены и коды возможностей из naming-standard. Реестр каталога и профилей: [CATALOG.md](../CATALOG.md). Как устроен каталог: [docs/catalog.md](../docs/catalog.md).

`ids.lock` генерирует `scripts/generate.py`. Номер из журнала не выдаётся повторно, требования не удаляют, а переводят в `deprecated`.
