# T-IAM-006: Автоматическое заведение и отключение учётных записей

## Требование
`req~T-IAM-006~1`

Система должна заводить и отключать учётные записи по данным корпоративного каталога пользователей без ручных действий.

Needs: impl, itest
Tags: directory

## Обоснование
Ручное отключение уволенных сотрудников запаздывает. Синхронизация с каталогом закрывает этот разрыв.

## Критерии приёмки
- Учётная запись создаётся при первом входе или по событию каталога, например через SCIM
- Пользователь, отключённый в каталоге, отключается в системе не позже чем через `{deprovision_minutes}` минут
- Отключение не удаляет данные и историю действий пользователя

## Параметры

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `deprovision_minutes` | 60 мин | максимальное время отключения после отключения в каталоге |
