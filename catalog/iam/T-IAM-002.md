# T-IAM-002: Второй фактор для каждого интерактивного входа

## Требование
`req~T-IAM-002~1`

Система должна требовать второй фактор аутентификации при каждом интерактивном входе пользователя, включая аварийную учётную запись.

Needs: impl, itest
Tags: sso

## Обоснование
Пароль без второго фактора остаётся главной причиной захвата учётных записей. Требование относится ко всем путям входа, а не только к локальным учётным записям.

## Критерии приёмки
- Вход пользователя без зарегистрированного второго фактора не завершается
- Аварийная учётная запись тоже требует второй фактор, её использование попадает в журнал аудита
- Список допустимых факторов задан политикой и соответствует уровню AAL2 или выше по NIST SP 800-63B
