# T-AI-001: Вызовы моделей только через корпоративный AI-шлюз

## Требование
`req~T-AI-001~1`

Система должна направлять каждый вызов языковой модели через корпоративный AI-шлюз с виртуальным ключом, без прямых обращений к провайдерам моделей.

Needs: impl, itest
Tags: gateway

## Обоснование
Шлюз даёт одну точку для учёта, лимитов, фильтров и выбора провайдера. Ключ провайдера в настройках пользователя обходит все эти меры.

## Критерии приёмки
- Адрес шлюза задаётся централизованно для всех агентов и исполнителей системы
- Ключей провайдеров моделей нет в настройках пользователей и в рабочих областях агентов
- Прямое соединение с API провайдера из среды исполнения отклоняется сетью
