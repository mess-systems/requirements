# T-AI-004: Бюджеты расходов на модели с блокировкой

## Требование
`req~T-AI-004~1`

Система должна блокировать вызовы моделей при исчерпании бюджета пользователя, проекта или процесса за период `{budget_period}`.

Needs: impl, itest
Tags: gateway

## Обоснование
Учёт без лимита показывает перерасход только после того, как деньги потрачены.

## Критерии приёмки
- Бюджет задаётся отдельно для пользователя, проекта и процесса
- Вызов сверх бюджета отклоняется с понятным сообщением, событие попадает в журнал
- Владелец бюджета получает уведомление при расходе `{warn_percent}` % бюджета

## Параметры

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `budget_period` | month | период бюджета: day, week или month |
| `warn_percent` | 80 % | порог предупреждения |
