# T-AI-003: Экспорт трассировок вызовов моделей по OTLP

## Требование
`req~T-AI-003~1`

Система должна экспортировать трассировки вызовов моделей и работы агентов во внешнюю систему по протоколу OTLP.

Needs: impl, itest
Tags: llm-traces

## Обоснование
Внутренняя телеметрия, доступная только в интерфейсе системы, не сопоставляется с трассировками шлюза и других сервисов.

## Критерии приёмки
- Адрес приёмника OTLP задаётся конфигурацией
- Атрибуты спанов следуют семантическим соглашениям OpenTelemetry для генеративного ИИ
- Тексты запросов и ответов передаются только при явно включённой настройке
